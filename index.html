MANUAL

計測値の見方

dBFS
デジタルフルスケール基準の音量レベル。0 dBFS が最大値で、それ以下の負の値で表されます。 −12〜−3（黄色）は大きめ、−3 以上（赤）はクリップ寸前です。 通常の会話・環境音は −40〜−20 dBFS 付近。
dBSPL
CAL ボタンで基準音源（騒音計など）とキャリブレーションした後、dBSPL ON に切り替えると表示されます。 実際の音圧レベル（0 dB = 20 μPa 基準）に対応する値です。
dBA
人間の聴覚特性（A 特性）に合わせて周波数補正した音量。低音・高音を耳に近い形で重み付けしており、 騒音規制や職場環境の評価でよく使われます。dBFS より若干低めの値になることが多いです。
LUFS-M（Momentary）
直近 400 ミリ秒のラウドネス。瞬間的な音量の大小を素早く反映します。 音楽・音声のリアルタイムモニタリングに最適。EBU R128 / ITU-R BS.1770-4 準拠。
LUFS-S（Short-term）
直近 3 秒間のラウドネス。LUFS-M より変動が少なく、 シーン単位の音量感をつかむのに向いています。
LUFS-I（Integrated）
計測開始からの累積ラウドネス。放送・配信の規格値として使われます。 ターゲット：放送 −23 LUFS（EBU R128）、ストリーミング −14 LUFS（Spotify/YouTube 目安）。 ゲーティング処理（無音区間を除外）が入るため、静寂が長くても値が下がりにくいです。

グラフ・メーターの見方

WAVEFORM（波形）
マイク入力の時間波形。振れ幅が大きいほど音が大きいです。 左右対称に広がらず偏っている場合は DC オフセットが乗っている可能性があります。
LED バーグラフ
左から dBFS / dBA / LUFS-I の 3 チャンネル。上端に光る細いセグメントがピークホールドで、 直近のピーク値を約 1 秒保持した後ゆっくり下降します。
SPECTRUM（スペクトラム）
周波数成分をリアルタイム表示。横軸は対数スケール（左：低音域 20Hz、右：高音域 20kHz）。 縦軸が高いほどその周波数のエネルギーが大きいです。 空調・換気の低音ノイズや、特定の機器ノイズの周波数特定に役立ちます。
アナログ針メーター
dBFS を VU メーター風に表示。バネ物理シミュレーションで慣性・減衰をリアルに再現しています。 瞬間値よりも「音の雰囲気」を直感的につかむのに適しています。
HIST（履歴グラフ）
直近 5 分間の dBFS（緑）/ dBA（黄）/ LUFS-I（紫）を折れ線で表示。 IndexedDB に保存されるため、ページを閉じても残ります。CLEAR で全削除できます。

ボタンの使い方

▶ START
マイクへのアクセスを要求して計測を開始します。初回はブラウザの許可ダイアログが表示されます。
⏺ REC
音声録音を開始します（START の後に押せます）。録音中はボタンが点滅します。 STOP を押すと録音ファイルが自動的に保存されます（iOS は共有シートが開きます）。
■ STOP
計測と録音を終了します。録音中だった場合はファイルの保存処理が走ります。
CAL
dBSPL キャリブレーションパネルを開きます。 騒音計などの基準値を入力して「保存」するとオフセットが記録されます。 その後 dBSPL ON にすると補正済みの値が表示されます。
PEAK RST
LED バーグラフのピークホールドをリセットします。新しい最大値を測り直したいときに使います。
dBSPL OFF / ON
OFF のとき：dBFS / dBA（生の測定値）を表示。
ON のとき：CAL で設定したオフセットを加算した dBSPL / dBSPL(A) を表示。 キャリブレーション前は ON にしても値は変わりません。
HIST
計測履歴グラフを表示／非表示します。直近 5 分間のトレンドを折れ線グラフで確認できます。

よくある質問

値が表示されない / ---.- のまま
START ボタンを押してからマイクの許可を与えてください。HTTPS または localhost 環境が必要です。
iOS で録音ファイルが保存できない
iOS Safari では共有シートが開きます。「ファイルに保存」を選んでください。PWA モードでは共有シートのみ対応です。
画面が暗くなる
Screen Wake Lock が取得できていない可能性があります。タイトルバー右の ⊙ インジケーターが緑なら有効です。ブラウザの省電力設定を確認してください。
