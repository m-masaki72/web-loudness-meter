計測値の見方

dBFS
デジタルフルスケール基準の音量。0 dBFS が最大値。 −12〜−3（黄）は大きめ、−3 以上（赤）はクリップ寸前。 会話・環境音は −40〜−20 dBFS 付近が目安。
dBSPL
CAL でキャリブレーション後、dBSPL ON にすると表示される実際の音圧レベル（0 dB = 20 μPa）。
dBA / dBC
dBA：人の聴覚特性（A 特性）で補正した音量。騒音規制の基準として広く使われます。
dBC：C 特性補正（低音を重視）。内部計算のみで数値表示はありません。
LUFS-M / S / I
ITU-R BS.1770-4 準拠のラウドネス（EBU R128）。
M：直近 400ms（瞬間値）　S：直近 3s（シーン値）　I：計測開始からの累積
放送ターゲット：−23 LUFS、ストリーミング目安：−14 LUFS。 I はゲーティング処理で無音区間を除外します。

グラフ・メーターの見方

WAVEFORM（波形）
マイク入力の時間波形。振れ幅が大きいほど音が大きいです。 左右対称に広がらず偏っている場合は DC オフセットが乗っている可能性があります。
LED バーグラフ
左から dBFS / dBA / LUFS-I の 3 チャンネル。上端に光る細いセグメントがピークホールドで、 直近のピーク値を約 1 秒保持した後ゆっくり下降します。
SPECTRUM（スペクトラム）
周波数成分をリアルタイム表示。横軸は対数スケール（左：低音域 20Hz、右：高音域 20kHz）。 縦軸が高いほどその周波数のエネルギーが大きいです。 空調・換気の低音ノイズや、特定の機器ノイズの周波数特定に役立ちます。
アナログ針メーター
dBFS を VU メーター風に表示。バネ物理シミュレーションで慣性・減衰をリアルに再現しています。 瞬間値よりも「音の雰囲気」を直感的につかむのに適しています。
HIST（履歴グラフ）
dBFS（緑）/ dBA（黄）/ LUFS-M（水色）/ LUFS-I（紫）を折れ線で表示。 5min / 30min / ALL で期間切替、CLEAR で全削除。ページを閉じても保持されます。

ボタンの使い方

▶ START
マイクへのアクセスを要求して計測を開始します。初回はブラウザの許可ダイアログが表示されます。
⏺ REC
音声録音を開始します（START の後に押せます）。録音中はボタンが点滅します。 STOP を押すと録音ファイルが自動的に保存されます（iOS は共有シートが開きます）。
■ STOP
計測と録音を終了します。録音中だった場合はファイルの保存処理が走ります。
CAL
dBSPL キャリブレーションパネルを開きます。 騒音計などの基準値を入力して「保存」するとオフセットが記録されます。 その後 dBSPL ON にすると補正済みの値が表示されます。
PEAK RST
LED バーグラフのピークホールドをリセットします。新しい最大値を測り直したいときに使います。
dBSPL OFF / ON
OFF：生のデジタル値（dBFS / dBA）を表示。
ON：CAL で設定したオフセットを加えた音圧値（dBSPL / dBSPL(A)）を表示。CAL 未設定では変化しません。
HIST
計測履歴グラフを表示 / 非表示します。
SIMPLE / EXPERT
タイトルバー右端で切り替えます。
SIMPLE（初期）：波形・騒音レベル・dBFS のみ。はじめての方向け。
EXPERT：LED バー・スペクトラム・全数値・録音など全機能。設定はブラウザに保存されます。
⊙ ウェイクロック
タイトルバーのインジケーター。緑なら Screen Wake Lock 有効（画面オフを防止）、灰色なら無効または非対応です。

よくある質問

値が表示されない / --- のまま
START ボタンを押してからマイクの許可を与えてください。HTTPS または localhost 環境が必要です。
iOS で録音ファイルが保存できない
iOS Safari では共有シートが開きます。「ファイルに保存」を選んでください。PWA モードでは共有シートのみ対応です。
画面が暗くなる
Screen Wake Lock が取得できていない可能性があります。タイトルバー右の ⊙ インジケーターが緑なら有効です。ブラウザの省電力設定を確認してください。
